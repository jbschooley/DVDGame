# DVD Game

A simple game based on the bouncing DVD logo we all grew up with. Plan written by Sonnet 4.6, all code generated with gemma-4-31B-it-UD-Q4_K_XL. Readme written by me, I don't vibecode my english.

# Instructions

```shell
npm install
npm run dev
```

Use WASD, arrow keys, or swipes to control the logo's direction and try to hit corners. The closer you get to a corner, the more points you earn. You cannot hit the same corner twice. Every time you hit an edge, it gets faster. You have 1 minute to score as many points as possible.
